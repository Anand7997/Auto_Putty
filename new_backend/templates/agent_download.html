🚀 Local Test Execution Agent

📋 What is this?

The Local Test Execution Agent allows you to run automated tests on your local machine when triggered from our web application. Instead of tests running on the server, they will execute in your local Chrome browser.

📋 System Requirements

  • ✅ Python 3.7 or higher
  • ✅ Google Chrome browser
  • ✅ Internet connection
  • ✅ Windows, macOS, or Linux

📦 Download Test Agent Package
Package includes: Agent software, installer, and documentation

🔧 Installation Steps

Step 1: Download and extract the agent package to a folder on your computer.
Step 2: Open a command prompt/terminal in the extracted folder.
Step 3: Run the installer:

Windows: python install_agent.py --server {{SERVER_URL}}
Linux/Mac: python3 install_agent.py --server {{SERVER_URL}}
Step 4: Start the agent using the desktop shortcut or startup script created during installation.
Step 5: Your agent should appear in the "Connected Agents" section below when running.

⚠️ Important Notes

  • Keep the agent running while you want to execute tests locally
  • Make sure Chrome browser is installed before running the installer
  • The agent will automatically download and manage ChromeDriver
  • Tests will open in a new Chrome window on your machine
