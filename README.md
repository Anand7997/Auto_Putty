🚀Selenium Test Automation Framework
A modern, full-stack test automation system for web applications, featuring a React + Vite frontend, Flask backend, SQL Server integration, and advanced Selenium-based test execution with Allure reporting.

✨ Features
Frontend: React + Vite UI for project, test case, and step management
Backend: Python Flask API with Selenium test executor
Database: SQL Server for storing projects, test cases, and results
Allure Reports: Rich, interactive test reports with screenshots, logs, and metrics
Window/Tab Management: Advanced Selenium window handling and action types
Isolation Mode: Run tests with element-level isolation for robust reporting
Environment Support: Local and team (dev tunnel) environments with easy switching
